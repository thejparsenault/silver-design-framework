# Silver 0.9.0 — Meet the Work Where It Is

Silver 0.9.0 helps a design practice work safely with the repositories, design
systems, and tools it already has. It is a release for starting with real work
rather than a blank slate.

## Highlights

- **Work with existing material.** Reviewable adoption, linked sources, and
  explicit synchronization connect a Silver workspace to a design system,
  component catalog, codebase, or captured Figma representation without
  silently overwriting either side.
- **A workspace-owned design system.** Every new workspace includes an editable
  `design/system/` with token source, component catalog, rendered expression,
  and showcase.
- **Safer lifecycle operations.** Managed writes reject unsafe links;
  migrations, updates, and synchronization use recoverable transactions; and
  `silver recover` can resume or roll back an interrupted operation.
- **Better tool guidance.** Silver records how it selected a transport,
  distinguishes missing prerequisites from configuration problems, and explains
  what to do next.
- **Clearer browser checks.** A completed accessibility, responsiveness, or
  interaction finding is distinct from an unavailable browser or a
  navigation/protocol/inspection failure.
- **A fuller design vocabulary.** The framework now ships 25 skills, including
  `collect`, `structure`, `measure`, and `reconcile`.

## Install on macOS

The signed, notarized package is the simplest installation for most designers:

- `Silver-0.9.0-macos-arm64.pkg` for Apple Silicon Macs.
- `Silver-0.9.0-macos-x64.pkg` for Intel Macs.

Each package installs the `silver` command for macOS 13 or later without
requiring Node.js, npm, or Bun. The command is also available through the npm
package for agent-managed and cross-platform workflows.

## Verification

This release passed the source suite, exact packaged-workspace smoke test,
native builds for Apple Silicon and Intel, production dependency audit, and
macOS package validation. Both macOS installers are Developer ID signed,
Apple-notarized, stapled, and accepted by Gatekeeper.
