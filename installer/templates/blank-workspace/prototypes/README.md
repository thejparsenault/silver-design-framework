# Prototypes

Prototypes are open-ended and may be revised, promoted, retained, or discarded.
Each prototype records its own constraint profile. The default is
`constrained`; `partial` or `suspended` must be explicitly selected and never
changes the canonical design system.

The project-local prototype skill can initialize metadata and create an
editable static walkthrough from an exactly pinned portable-flow revision.
Generated prototype code must still use approved semantic styles.
