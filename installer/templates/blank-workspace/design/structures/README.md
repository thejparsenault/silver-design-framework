# Structures

Information architecture, navigation structure, content models, and object
models live here — what exists, how it is organized, and how things relate.
Each structure is one `silver/structure/v1` document, for example
`design/structures/account-hierarchy.json`.

Distinguished from `design/flows/` (sequences over time) and `design/maps/`
(journeys, service blueprints, and ecosystems): a structure records what
things are and how they relate, not what happens or who experiences it.
